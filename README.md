# Catalyst Windows Installer

This repository distributes the Catalyst Windows installer through GitHub Releases. Download the installer from the [latest release](https://github.com/svxvdxcszsz/catalyst-windows-installer/releases/latest).

## Requirements and limitations

- Target architecture: Windows x64.
- Microsoft Edge WebView2 Runtime must already be installed. The installer uses `webviewInstallMode: skip` and does not install the runtime.
- This installer was cross-compiled on Linux and has not been executed or GUI-tested on real Windows.
- Windows signing and SmartScreen reputation have not been verified.

See each release for the installer checksum and release-specific details.
